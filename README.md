# Ender Dragon Adaptive Rewards

Fabric 1.21.1 mod that adds progressive, configurable Ender Dragon rewards with secure owner-only reward chests.

Discord-MC-Chat integration is optional. When DMCC is installed, reward announcements post as Discord embeds from the DMCC bot in the same channel DMCC uses for Minecraft-to-Discord messages. The integration supports the stable 2.x mod id (`discord-mc-chat`) and the v3 beta mod id (`discord_mc_chat`).
